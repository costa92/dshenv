🗃️ 独立配置存储
DSHENV_HOME · dshenv 自有数据目录，可放在任意文件系统
📁 <DSHENV_HOME>/ 默认 <DSH_HOME>/envctl
├─📄 manifest.yaml# 期望状态（含全局层）
├─📄 lock.json# 精确版本 / 提交 / 摘要
├─📄 state.json# 所有权与同步基线
├─📄 overlay-selection.json# 本机选择
├─📁 overlays/# 多环境差异
├─📁 skills/# 声明的 Skills
├─📁 sources/# 受管 Git 克隆
├─📁 remote/ · remote.json# 团队仓库
├─📁 backups/# 快照
├─📁 trash/# 被替换的旧副本
├─📁 logs/# journal.jsonl
├─📁 run/# dsh web 进程记录
└─🔒 dshenv.lock# 环境锁
✔ 不允许软链接 · migrate --to <dir> 搬迁并改写旧路径
✔ DSH 从不读取此目录

📦 运行平面 · DSH
DeepSeek Harness · --dsh-home / DSH_HOME / ~/.dsh
📁 ~/.dsh/
├─📄 cordis.patch.yml# 全局层新
├─📁 profiles/<profile>/
│ ├─📄 package.json# bundles · 依赖
│ ├─📄 cordis.patch.yml# 受管块
│ └─📁 node_modules/# DSH 安装
├─📁 skills/# 复制进来
├─📁 sessions/# 不读不写
├─📁 storages/# 不读不写
├─📁 logs/# 不读不写
└─🔑 .credentials.yaml# 从不触碰
dshenv 写入方式：
• 插件：调用 dsh plugin（DSH_HOME=主目录）
• 启停：改 dsh.profile.bundles
• 配置：Profile 与全局 cordis.patch.yml 受管块（全局层后应用、同 id 覆盖）
• Skills：复制，旧副本进 trash
• 外部 skill 目录：customSkillDirs 由 DSH 直接读
✔ DeepSeek Harness 无需任何改动
🔄配置同步流程
先预览后执行：不加 --yes 只预览，有待办时退出码 2。

写入前打快照，全程持有环境锁，失败自动撤销。

🧭目录解析优先级
dshenv 数据目录
  1. --envctl-dir（参数）
  2. DSHENV_HOME（环境变量）
  3. <DSH_HOME>/envctl（默认）
Harness 运行目录
  1. --dsh-home（参数）
  2. DSH_HOME（环境变量）
  3. ~/.dsh（默认）
DSH 命令
  1. --harness-source → DSH_CLI
  2. 清单 sourceDir → PATH 中的 dsh
🧩多环境配置（Base + Overlay）
📁 <DSHENV_HOME>/
├─📄 manifest.yaml# Base
└─📁 overlays/
   ├─📄 laptop.yaml
   ├─📄 ci.yaml
   └─📄 local.yaml# pull 写入的本机路径
# 选择 overlay
dshenv overlay use laptop
dshenv --overlay ci plan
DSHENV_OVERLAY=ci dshenv apply --yes
🧱Skills / Plugins 来源与同步
📚 Skills
envctl/skills → 复制到 ~/.dsh/skills；DSH 里的修改由 pull 收回；可快照、回滚
📁 外部目录
DSH customSkillDirs 直接读取任意目录并监视；dshenv 经补丁 + 本机 overlay 管理该配置
🔌 Plugins
npm 精确版本 · git url + commit · local-link / local-file（任意路径）· in-box
🔁 同步方式
Skill 复制；本地插件由 pnpm link: / file: 引用；不使用 symlink
⚔️ 冲突
默认报错；--prefer dsh|manifest 指定以哪边为准
规划中：冲突跳过 --prefer skip
